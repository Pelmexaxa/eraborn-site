# Наследие эпох · Eraborn: Legacy

Карточная стратегия один на один: проведите державу через Античность, Средневековье и Индустриальную эпоху.

Это веб-версия игры. Работают обучение и игра против ИИ, игра по локальной сети есть только в приложении для ПК и Android.

## Что здесь лежит

Готовая сборка, её не нужно собирать: `index.html`, папка `assets` (код, графика, звук) и значки. Файл `.nojekyll` отключает обработку Jekyll на GitHub Pages: сайт отдаётся как есть.

## Как обновить

Сборка делается в проекте игры:

```
npm run build:web
```

Потом содержимое `game/dist-web` копируется сюда целиком, с заменой старых файлов, а `.nojekyll` и этот README остаются.
